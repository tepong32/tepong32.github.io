The problem

File synchronization should not require blind trust

In shared-file environments, a copy can replace newer work or move files in the wrong direction. TraceSync compares first, shows differences, requires a direction, previews exact changes, and asks for confirmation.

Engineering decisions

Safety is an architectural constraint, not a warning dialog

Explicit direction

One-way synchronization avoids ambiguous conflict resolution and makes user intent inspectable.

Immutable preview contract

Only reviewed, eligible files enter a job; per-file selection preserves operator control.

Pre-copy revalidation

Source and destination metadata are checked again immediately before each copy.

Honest failure semantics

Execution results remain truthful even when final history persistence fails.

Engineering maturity

Evidence beyond the happy path

79 automated tests

Coverage spans comparison confidence, preview selection, copy safety, settings, UI behavior, persistence, export, and history recovery.

Atomic audit records

Versioned JSON run records use validated identities, interrupted-run recovery, and bounded retention.

Security-aware export

CSV output protects spreadsheet users against formula injection and exports only the selected run.

Concurrency control

A per-user operating-system lock prevents overlapping synchronization jobs without overstating distributed guarantees.
