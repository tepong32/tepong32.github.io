TraceSync

A Windows utility that compares two folders, explains every difference, and requires an explicit preview and confirmation before copying files.

The problem

File synchronization should not require blind trust

In shared-file environments, a copy can replace newer work or move files in the wrong direction. TraceSync compares first, shows differences, requires a direction, previews exact changes, and asks for confirmation.

Engineering decisions

Safety is built into the workflow

One-way by design

Users explicitly select Local → Server or Server → Local.

Complete preview

New files, replacements, and warnings appear before confirmation.

Metadata revalidation

Files changed after confirmation are skipped.

Recoverable execution

File-level errors do not stop other approved copies.
